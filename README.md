How many tabs do you have open? **1** — one single tab: the repository page
for this very entry, open in the browser session that built it. No tab
hoard, no graveyard of half-read articles, just the one tab doing the work.
The program writes exactly that one digit to `/output/entry.txt` — nothing
else, no words, no punctuation.

## Run it

python3 main.py
